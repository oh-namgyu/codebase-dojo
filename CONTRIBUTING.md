# Contributing to codebase-dojo

Thanks for your interest! This is a **Claude Code skill** — prose and
instructions, not code, so there's nothing to build or test.

## How to propose changes

- The skill itself lives in `SKILL.md`; tweaks to the Socratic lenses, question
  wording, or journal format go there.
- Keep it provider-neutral and keep external links live (`README.md` cites prior
  art and a study — verify links still resolve if you touch them).
- Try your change locally by cloning into `~/.claude/skills/codebase-dojo` and
  invoking `/codebase-dojo` in Claude Code.

Open an issue or PR describing the improvement and the reasoning behind it.
