# codebase-dojo (한국어 소개)

> 코드베이스를 위한 **소크라테스식 튜터**. 답을 주지 않고 **"왜?"**를 캐묻는다. [Claude Code](https://docs.claude.com/en/docs/claude-code) 스킬.

[English README](README.md)

## 어떤 문제를 푸나

AI 코딩 도구는 이해를 줄이면서 *빠르다는 느낌*을 줍니다. 도구에 너무 기대면 코드의 **감독자(director)** 에서, AI 산출물을 그냥 승인하는 **operator** 로 미끄러집니다 — 결정을 다시 따져보지 않고 믿음으로 도장 찍게 되는 거죠. codebase-dojo 는 그 평형추입니다. 답을 건네는 대신, 스스로 결론을 **다시 도출하게** 만듭니다.

## 핵심 기능

- 코드베이스의 설계 결정에 대해 **왜·대안·결과**를 캐묻는 소크라테스식 문답
- 사실 암기가 아니라 **판단력 훈련**이 목표
- Claude Code 스킬로 동작 (`/학습` 한국어판의 영어 공개판)

## 이 프로젝트의 핵심 포인트

"AI 가 코드를 더 빨리 짜준다"는 흐름에 **정면으로 역행하는** 도구입니다. 답을 거부하고 사용자가 직접 재도출하게 만들어, AI 시대에 개발자가 코드의 감독자 자리를 지키게 하는 게 설계 철학입니다. ([2025년 무작위 연구][metr]에서 숙련 개발자가 AI 보조로 오히려 *느려졌으면서도* 빨라졌다고 믿었다는 결과가 출발점.)
